# הון. — דגם לתוכנת הצהרות הון

פרויקט עצמאי של משרד עבדי בן גל, נפרד לחלוטין ממאגר `abady-crm`.

## הפעלה

Node 24 ו־npm 11 נבדקו בסביבה.

```bash
npm ci --cache /tmp/abady-capital-npm-cache --no-audit --no-fund
npm run dev
```

שרת הפיתוח משתמש בפורט 5174. בדיקות: `npm test`; בנייה: `npm run build`.

## הדגם

תיק לדוגמה, איסוף מסמכים, הדמיית OCR ובדיקת ספרים, שורות הצהרה ניתנות לעריכה,
השוואת הון ומקורות/שימושים, דוח סוכן בדיקה, פורטל לקוח וטיוטות מייל/וואטסאפ
המחייבות אישור לפני הדמיית שליחה. עריכת הודעה או נתוני תיק מבטלת אישור קודם.

הדגם שומר נתוני דוגמה ב־localStorage של הדפדפן ויכול להוריד גיבוי ונייר עבודה.
צירוף קובץ רושם שם קובץ בלבד. התוכן אינו נשמר, אינו נשלח ואינו עובר OCR אמיתי.
אין שליחת מייל/וואטסאפ, הגשה לרשות המסים או חיבור למסד נתונים בשלב זה.
מיפוי למהדורה העדכנית של טופס 1219 עדיין מחייב אימות.

## הפרדה מה־CRM

אין בפרויקט קוד CRM, מפתחות, חיבור Supabase או נתוני לקוחות אמיתיים.
יש ליצור פרויקט Supabase חדש ומבודד לתוכנת ההון; אין להשתמש בפרויקט ה־CRM.
לא הופעלו שינויים בסכמה או במידע של מסד ה־CRM.
את כתובת הפרויקט החדש ואת המפתח הציבורי יש להוסיף בעת מימוש החיבור בפועל.
אין להכניס מפתח `service_role` לקוד דפדפן או למאגר.
