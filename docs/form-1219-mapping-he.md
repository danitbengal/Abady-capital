## מבנה נתונים מומלץ

המערכת תשתמש במנוע טפסים לפי גרסה:

- `form_versions`: קוד טופס, תאריך תחולה, checksum וקובץ מקור פרטי.
- `declaration_versions`: גרסת עבודה, סטטוס, תאריך הצהרה ותאריך הגשה.
- `form_entries`: קוד שורה רשמי, בעלים, סכום ₪, מטבע וסכום מקור, וסוג רשומה.
- `entry_details`: שדות ייחודיים לקטגוריה לפי JSON Schema בעל גרסה.
- `business_entities`: עסק/שותפות/חברה, אחוז החזקה וסוג הנהלת חשבונות.
- `calculated_totals`: תוצאות מחושבות לפי קודי הטופס; אין עריכה ידנית.
- `document_links`: קישור מסמך או נספח לרשומה ולקוד השורה הרשמי.
- `declaration_snapshots`: צילום בלתי משתנה של הנתונים שאושרו ונשלחו לחתימה.

עדכון כרטיס לקוח אינו משנה snapshot שאושר. עדכון מועדים מרשות המסים יוצר אירוע ביקורת ומשנה רק את שדות המועד בגרסת העבודה.
